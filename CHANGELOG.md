# Changelog

## 0.2.0

- Added persistent one-time approval queue for noninteractive clients.
- Added project metadata: start/test commands, health URL, auto-restart and restart cap.
- Added persistent process supervision, log tailing, restart and stop behavior.
- Added deterministic crash detection and bounded automatic recovery.
- Added project health checks.
- Added polling filesystem watches.
- Added desktop notifications.
- Added due-reminder notifications and recent event history.
- Added local control dashboard and additional API endpoints.
- Added user-confirmed reusable prompt skills.
- Added resource guard and per-profile model context settings.
- Added Windows/Linux/macOS startup helper scripts.
- Added migration support for v0.1 project registry/todo schema.
- Expanded test suite from 9 to 15 tests.
