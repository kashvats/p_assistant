# Roadmap

## v0.2 — Desktop operator
- System tray UI with action approval cards.
- File diffs before overwrite.
- Native notifications.
- Better process log streaming.
- Browser automation through a constrained driver.
- Clipboard tools.
- Per-project virtual environment discovery.

## v0.3 — Personal life layer
- Calendar connector.
- Email connector.
- Morning brief.
- Voice STT/TTS and optional wake word.
- Local contact book.
- Scheduled routines with explicit permission profiles.

## v0.4 — Stronger security guardian
- Startup/persistence inventory per OS.
- Watched-folder integrity baselines.
- Signed executable metadata.
- VirusTotal/hash reputation optional integration.
- Quarantine workflow.
- Network baselines.

## v0.5 — Learning and plugins
- User-confirmed skill learning.
- Plugin SDK and signed plugin manifests.
- Optional local embeddings.
- Better long-term memory controls.
- Evaluation harness to compare specialist models per task and hardware.
