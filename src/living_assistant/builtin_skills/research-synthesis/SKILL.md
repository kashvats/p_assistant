# Research synthesis

## When to use
A task asks to find out, compare, or summarize what is known about something.

## Steps
1. Split the question into 2-5 sub-questions.
2. Search and read sources for each (web_search, then read the pages); prefer primary sources (official sites, papers, documentation).
3. Note for every finding the source URL and a short supporting quote.
4. Synthesize: the answer first, then the key findings, where sources disagree, and what is still unknown.
5. Rate confidence (high/medium/low) by the number and quality of independent sources.

## Rules and checks
- No claim without a source you actually read.
- Separate facts from your own conclusions.
