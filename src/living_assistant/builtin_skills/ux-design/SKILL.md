# Ux design

## When to use
A task asks for screens, layouts, a user flow, or the look and behaviour of an interface.

## Steps
1. List the user's main flows step by step (what they see, what they click, what happens).
2. For each screen describe the layout top to bottom, the components, and the empty, loading and error states.
3. Choose a small consistent system: 1 font, a spacing scale (4/8/16/24 px), 1 accent colour, readable contrast.
4. When the task asks for a mockup, produce real HTML/CSS (or the project's UI framework) rather than prose.
5. Note accessibility: labels for inputs, keyboard focus order, text contrast of at least 4.5:1.

## Rules and checks
- Every action the user can take must have visible feedback.
- Design only the screens the requirements need.
