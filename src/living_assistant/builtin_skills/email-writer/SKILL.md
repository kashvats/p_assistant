# Email writer

## When to use
Any request to write a new email or chat message, reply to one, or rewrite one in a different tone or length.

## Steps
1. Work out: who it is to, what the user wants to happen after it is read, the tone (formal, friendly, firm), and any facts that must be in it. Ask one short question only if the goal or recipient is unknown.
2. Write a subject line (for emails) that says what the email is about in under 8 words.
3. Open with the point in the first sentence. Then give the needed details, then one clear ask or next step with a date if there is one.
4. Keep it short: 3-6 sentences for most emails. Use a list only for 3 or more items.
5. Match the user's language and, when replying, the formality of the email being answered.
6. Show the draft. Offer one alternative only if the tone choice was unclear.

## Rules and checks
- Never send an email or message yourself; the user sends it (sending needs their approval).
- Do not invent facts, dates, prices or promises the user did not give; leave a clearly marked [placeholder].
- Check names, dates and numbers against what the user wrote before showing the draft.
