# Web fact check

## When to use
The question depends on current or external facts (versions, prices, news, opening hours, "is it true that ...").

## Steps
1. Turn the question into 1-3 short search queries.
2. Search, then read the 2-4 most relevant pages - prefer official sites, primary sources and recent dates.
3. Answer in 1-3 sentences first, then list the sources as [1], [2] with their titles and dates.
4. If sources disagree, say so and say which is more reliable and why. If nothing answers it, say that plainly.

## Rules and checks
- Search snippets alone are not evidence; read the page.
- Compare dates with today's date; say when information may be out of date.
- Never invent a source, quote or number.
