# Meeting notes

## When to use
The user gives a transcript, rough notes or a recording summary and wants minutes, a recap or action items.

## Steps
1. Read everything first. Identify the meeting purpose, date and attendees if stated.
2. Write the minutes in this order:
   - **Summary** - 2-3 sentences: what the meeting was for and the outcome.
   - **Decisions** - each decision as one line.
   - **Action items** - a table: action | owner | due date. Use "unassigned" / "no date" when the notes do not say.
   - **Open questions** - things raised but not settled.
   - **Key discussion points** - short bullets, only what matters later.
3. If the notes are in a file, read it with the file tools; for long files read them in parts.
4. Offer to save the minutes as a file (needs the user's approval) or turn the action items into todos.

## Rules and checks
- Only record what the notes say; never invent owners, dates or decisions.
- Keep names exactly as written.
- Every action item must start with a verb.
