# Editing

## When to use
A draft needs review before it is delivered.

## Steps
1. Read the whole draft once for structure: does it answer the brief, in a logical order?
2. Fix clarity (cut wordiness, split long sentences), then grammar and spelling, then consistency (names, terms, formatting).
3. Check every factual claim has a source or mark it.
4. Return the edited text plus a short list of the substantive changes.

## Rules and checks
- Keep the author's meaning and voice.
- Flag, do not silently remove, claims you cannot verify.
